# RIFT 3D — 召唤师峡谷网页 MOBA

基于 Three.js 的可玩单人 5v5 网页游戏。包含三路、河道、野区、两方基地、推塔与水晶胜负、AI 英雄和兵线、补刀经验金币、技能升级、战争迷雾与守卫、装备商店、回城与复活。

27 位英雄：阿狸、艾希、盖伦、拉克丝、伊泽瑞尔、亚索、提莫、金克丝、安妮、布兰德、莫甘娜、维迦、吉格斯、菲兹、易、李青、德莱厄斯、墨菲特、布里茨、蕾欧娜、薇恩、凯特琳、厄运小姐、娑娜、崔斯特、卡莎、卡蜜尔。每位有独立 QWER、被动与 3D 造型：包括钩子、提伯斯召唤、成长法强、连锁烈焰、三环真伤、二段突进、击飞与引导弹幕。AI 阵容会从职业池里选择不同英雄。

英雄收藏使用蓝色精粹解锁，阿狸、艾希、盖伦初始拥有。新玩家赠送 6,000 精粹，每日补给 1,200；普通对局每分钟 60、补刀 2、击杀 30、助攻 15，每局战斗奖励上限 1,200，胜利额外 1,500、失败 900。练习模式免费试用全部英雄、不发精粹，从 6 级和 10000 金币开始。精粹与英雄、皮肤、装备外观选择保存在当前浏览器，无真实货币支付或跨设备账户同步。

27 款原创主题皮肤支持旋转 3D 预览、购买与装备，包括薄荷浪客、蘑菇宇航员、苏打机器人、电玩终极王和糖果海盗。皮肤改变模型材质、主题附件与技能光色，不增加战斗属性。D / F 可在大厅配置两个不同的召唤师技能，默认为闪现与引燃。

这是独立制作的非官方网页游戏。3D 场景及模型为程序生成；英雄卡面和头像使用 Riot Data Dragon 公共资源。没有连接 Riot 游戏服务器，也没有玩家联网对战。

10 种召唤师技能：闪现、引燃、治疗、疾跑、屏障、虚弱、净化、传送、惩戒、清晰术。每种有独立目标规则、冷却和特效；传送引导需要己方塔、兵或眼，惩戒作用于野怪和敌方小兵，净化保留击飞。选择保存在当前浏览器，进入对局后固定。

27 位英雄的模型包含面部五官、分层服饰与装甲、精细武器等细节。大厅支持放大模型、拖动旋转与滚轮缩放，皮肤沿用对应细节。

```sh
npm install

npm run build
```

## 操作

右键移动或持续攻击；施法方式可在大厅、右上角按钮或暂停菜单切换并保存：手动施法按 QWER/DF/4 后左键确认，智能施法按键立即朝鼠标位置施放；Shift+技能临时使用另一种施法，自身技能始终立即生效。点击技能图标和触屏操作保留点选目标；Ctrl+QWER 或技能上的 + 升级。A 后左键点敌人精准攻击或点地面攻击移动，Shift+A 立即执行，S 停止，B 回城，4 插眼，P 商店，Tab 战绩，Y 切换视角锁定，按住空格居中，中键或空白地面左键拖动镜头，屏幕边缘或方向键快速平移，滚轮缩放。1/2/3/5/6/7 使用六个装备栏；Esc 取消操作或暂停。手机点地面移动、点敌人攻击、点技能后选目标。

114 件装备覆盖射手、法师、战士、坦克与辅助，商店支持搜索、职业推荐、属性筛选、散件自动抵扣、递归合成、满栏升级、装备出售与属性移除。点击成装时，金币不足会先购买递归配方中买得起的最贵一件散件（按目录原价比较，购买时抵扣已有部件）；每次点击只买一件，足额时直接合成。按 P 打开商店，选择“我的装备”中的栏位，再点击出售。普通装备返还原价 70%，多兰装备及消耗品返还 40%；六个装备栏与快捷键固定对应，物品耗尽或卖出不会挤动其他栏位。共享被动装备有唯一组限制，装备数值与效果以本项目说明为准。

亚索普通 Q 为前方直刺，叠满两层后的 Q 发射龙卷风；E 后短时间接 Q 为环形斩，叠风状态的 EQ 为环形击飞。

新增卡莎、卡牌大师与卡蜜尔：卡莎有五层电浆、孤立飞弹与装备驱动的 Q/W/E 进化；卡牌可二次 W 锁定三色牌，R 显露全图英雄后二次 R 传送，支持小地图落点；卡蜜尔的 E 必须命中真实地形，延迟 Q2 转为真实伤害，R 限制目标离开决斗圈。

战斗特效包含粒子拖尾、多层光束、冰晶、剑光、爆炸冲击波与持久陷阱模型。

`python3 scripts/fetch-assets.py` 下载新增英雄原画、头像、技能图标及装备图标。所有游戏用图保存在 `public/assets`，发布时直接托管；3D 模型与皮肤无需额外图片请求。

### Cloudflare Pages

构建目录为 `dist`，无后端或私密配置。已有 Cloudflare 登录后：

```sh
npx wrangler pages project create rift-moba-3d --production-branch main
npx wrangler pages deploy dist --project-name rift-moba-3d --branch main
```
