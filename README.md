# RIFT 3D — 召唤师峡谷网页 MOBA

基于 Three.js 的可玩单人 5v5 网页游戏。包含三路、河道、野区、两方基地、推塔与水晶胜负、AI 英雄和兵线、补刀经验金币、技能升级、战争迷雾与守卫、装备商店、回城与复活。

可选英雄：阿狸、艾希、盖伦、拉克丝、伊泽瑞尔、亚索、提莫、金克丝。包含亚索叠风击飞与风墙、提莫毒箭隐身与蘑菇陷阱、金克丝双枪切换与范围火箭，以及每位英雄的独立 QWER 技能机制。D 为闪现，F 为引燃。默认普通对局；练习模式从 6 级和 10000 金币开始。

这是独立制作的非官方网页游戏。3D 场景及模型为程序生成；英雄卡面和头像使用 Riot Data Dragon 公共资源。没有连接 Riot 游戏服务器，也没有玩家联网对战。

## 开发

```sh
npm install
npm run dev
npm run build
```

## 操作

右键移动或持续攻击；施法方式可在大厅、右上角按钮或暂停菜单切换并保存：手动施法按 QWER/DF/4 后左键确认，智能施法按键立即朝鼠标位置施放；Shift+技能临时使用另一种施法，自身技能始终立即生效。点击技能图标和触屏操作保留点选目标；Ctrl+QWER 或技能上的 + 升级。A 后左键点敌人精准攻击或点地面攻击移动，Shift+A 立即执行，S 停止，B 回城，4 插眼，P 商店，Tab 战绩，Y 切换视角锁定，按住空格居中，中键或空白地面左键拖动镜头，屏幕边缘或方向键快速平移，滚轮缩放。1/2/3/5/6/7 使用六个装备栏；Esc 取消操作或暂停。手机点地面移动、点敌人攻击、点技能后选目标。

装备商店支持散件自动抵扣、递归合成、满栏升级、装备出售与属性移除。按 P 打开商店，选择“我的装备”中的栏位，再点击出售。普通装备返还原价 70%，多兰装备及消耗品返还 40%；六个装备栏与快捷键固定对应，物品耗尽或卖出不会挤动其他栏位。

亚索普通 Q 为前方直刺，叠满两层后的 Q 发射龙卷风；E 后短时间接 Q 为环形斩，叠风状态的 EQ 为环形击飞。

战斗特效包含粒子拖尾、多层光束、冰晶、剑光、爆炸冲击波与持久陷阱模型。

### Cloudflare Pages

构建目录为 `dist`，无后端或私密配置。已有 Cloudflare 登录后：

```sh
npx wrangler pages project create rift-moba-3d --production-branch main
npx wrangler pages deploy dist --project-name rift-moba-3d --branch main
```
